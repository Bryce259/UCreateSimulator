\#UCreate simulator
#By Bryce Belcher
##Getting started
The Radica Ucreate DJ sampler and recorder was developed by Mattel in 2009, ages 8 and up. Though it was a kids toy, anyone could enjoy it because of the usability and features and how fun it was for it's time. Unfortunately it didn't last in the market, by two years they stopped selling them. However, you can by them on Ebay if they're in stock. This app simulates the experience of it wile at the same time adding or changing new things that weren't included In the unit. I developed this because at one point I had one, and thought how cool it would be to Have the experience in a web app.
##Installation
Install the UCreate Simulator Setup 1.0.0 file and run it as admen, choose The folder you'd like to install or leave it by default, and start the installation. a desktop shortcut will be added so you can run the app that way if you want.
##How to play
This app has been designed to be accessible with screen readers, so people who rely on them can use this app. Visuals and images will be added in a later time. Each lane can play one loop at a time; press its active pad again to mute it. Link lanes, choose an effect, then use the two sliders like the original distortion rocker. The controls support mouse, touch, keyboard, and screen readers. Previously the original toy only recorded music up to 2 minutes. because this is now a web app, it has been changed to unlimited, but recording a sample is still 5 seconds at the moment. You can only record samples, but the ability to add audio files will be added soon.
Each lane can play one loop at a time; press its active pad again to mute it. Link lanes, choose an effect, then use the two sliders like the original distortion rocker. The controls support mouse, touch, keyboard, and screen readers. You can change the tempo and speed of the loop. There are eight effects to choose from, from Flanger, step phaser, echo, rewind spin looper, f/r looper, low pass filter, distortion , and tremolo.
All the factory loops included in The unit are here. Each loop has all the instruments and sounds from the toy such as back beats, riffs, licks and runs, just as the toy had them. Note that the audio is in 8 KhZ Unsigned 8bit PCM. There might be clipping when adding loops together because of that. to avoid clipping you can turn the master volume down slightly when layering instruments. The volume is at 82% as default, but if you start to clip, change it to 50-35%, that should help.
If you're someone like me who once had the Ucreate, this ap is for you! If not, consider checking one out or using this app. Even if you have one, you'll still get a kick out of it!
