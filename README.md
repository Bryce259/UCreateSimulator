UCreate simulator
By Bryce Belcher
<h1>Getting started<h1>
<p></p>The Radica Ucreate DJ sampler and recorder was developed by Mattel in 2009, ages 8 and up. Though it was a kids toy, anyone could enjoy it because of the usability and features and how fun it was for it's time. Unfortunately it didn't last in the market, by two years they stopped selling them. However, you can by them on Ebay if they're in stock. This app simulates the experience of it wile at the same time adding or changing new things that weren't included In the unit. I developed this because at one point I had one, and thought how cool it would be to Have the experience in a web app.
<h2>Installation<h2>
<p></p>Install the UCreate Simulator Setup 1.0.1 file and run it as admen, choose The folder you'd like to install or leave it by default, and start the installation. a desktop shortcut will be added so you can run the app that way if you want.
<h3>How to play
<p></p>This app has been designed to be accessible with screen readers, so people who rely on them can use this app. this app now has visuals and images, and has a new look. I grabbed the control images from the user manual of the toy. The App Store remains accessible in the latest version. Each lane can play one loop at a time; press its active pad again to mute it. Link lanes, choose an effect, then use the two sliders like the original distortion rocker. The controls support mouse, touch, keyboard, and screen readers. Previously the original toy only recorded music up to 2 minutes. because this is now a web app, it has been changed to unlimited, and you can now record up to 10 seconds. You can also import aan audio file (max 10 seconds instead of five). Each lane can play one loop at a time; press its active pad again to mute it. Link lanes, choose an effect, then use the two sliders like the original distortion rocker. The controls support mouse, touch, keyboard, and screen readers. You can change the tempo and speed of the loop. There are ten effects to choose from, from Flanger, step phaser, echo, rewind spin looper, f/r looper, low pass filter, distortion, warped, Swirling, and tremolo. I added two more affects that were never used in the actual unit to see what it would be like ;ole.
All the factory loops included in The unit are here. Each loop has all the instruments and sounds from the toy such as back beats, riffs, licks and runs, just as the toy had them. Note that the audio is in 8 KhZ Unsigned 8bit PCM. There might be clipping when adding loops together because of that. to avoid clipping you can turn the master volume down slightly when layering instruments. The volume is at 82% as default, but if you start to clip, change it to 50-35%, that should help.
<h4>credets<h4>
<p>## Special Shoutouts

Huge shoutout to Ray Burns from the UCreate Music Facebook group! He shared the zip file containing all the factory loops, and without that file this whole project wouldn't be what it is today. If you go looking on the internet for these loops, you won't find them anywhere else — this is the only place they exist.

Here's the story behind the audio: these aren't the original studio masters. Ray got the loops from the actual UCreate app itself — they're the versions the app prepped and transferred to the device. They came as 8 kHz unsigned 8-bit PCM with a UCreate header and no WAV header, so the header had to be chopped off and the files imported into Audacity as raw audio at the suspected sample rate and bit depth. They've been resampled to 44.1 kHz since, but that can't bring back quality that was never there in the first place. What you hear is exactly what the 2009 hardware was working with, which honestly just makes this simulator even more authentic.

So thank you, Ray — this project exists because of you!
If you're someone like me who once had the Ucreate,   this ap is for you! If not, consider checking one out or using this app. Even if you have one, you'll still get a kick out of it!
